# AC not cooling: demo support guide

For an AC that is not cooling, ask for model, temperature setting, error code and when the problem started. Check the remote is set to cooling, close doors and windows, and check that external airflow is not obstructed. Clean only user-accessible filters according to the actual manufacturer manual after switching off the unit. Do not open electrical panels or handle refrigerant. Burning smell, smoke, exposed wiring or water near electrical parts require stopping use and professional service. This is generic demo guidance, not a model-specific manual.
